# MaidFinder Frontend

A React-based web application for connecting house help providers with customers.

## Features

- **Hire Button** - Allows customers to hire maids and mark them as unavailable
- **WhatsApp Integration** - Direct WhatsApp messaging with maids
- **Call Integration** - Direct phone calling functionality
- **Advanced Filters** - Filter by work type, location, availability, and living help
- **Responsive Design** - Works on desktop and mobile devices

## Deployment

This frontend is configured for Azure Static Web Apps deployment via GitHub Actions.

## Local Development

1. Install dependencies: `npm install`
2. Start development server: `npm start`
3. Build for production: `npm run build`

## Backend API

The frontend connects to a Flask backend API for maid data and hiring functionality.
